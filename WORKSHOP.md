[h1]Blueprints (Continued)[/h1]

Save a selection of built walls, floors and furniture as a named blueprint, then place copies of it, rotated, with a choice of stuff, as construction orders or as plans. Works on RimWorld 1.6 and 1.7 from one subscription. Compatible with existing saves.

This is a continuation of Fluffy's Blueprints: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=708455313]Fluffy's Workshop page[/url] and [url=https://github.com/fluffy-mods/Blueprints]Fluffy's source on GitHub[/url]. It is built only from Fluffy's own source (release v4.0.53); no code or files from any later Blueprints build were used.

[h2]How it works[/h2]

[list]
[*][b]Create:[/b] use the Create designator to drag over existing constructions. Floors, walls and furniture you own are saved, and you can name the blueprint.
[*][b]Place:[/b] pick the blueprint's button to place copies. Rotate as normal, and click an item in the lower left panel to change its stuff. Shift-click places the walls as plans.
[*][b]Rename, import and export:[/b] right-click a blueprint's button to rename, remove or export it. Exports go to the "Blueprints" folder next to your save games. Right-click Create to import one.
[/list]

[h2]Alpha Prefabs[/h2]

Alpha Prefabs' blueprint export only works with the Blueprints forks it names (package ids starting with defi.blueprints). It does not work with this mod.
